## できること

- **すべてのクエストを一か所に** – ゲーム・動画・アクティビティをタブで、残り時間とリアルタイムの進行リング付きで。
- **報酬がひと目でわかる** – Orbs、アバターデコ、プロフィールエフェクト、ゲーム内アイテム – 始める前に何がもらえるか分かります。
- **並べ替えとフィルター** – 終了が早い順、Orbsが多い順、短い順、新しい順。Discordコスメのみ、ミニ表示、小さいウィンドウ。
- **ワンクリックでセットアップ** – OrbekがVencordをダウンロードし、プラグインを追加してビルドし、Discordに組み込みます。手作業は不要です。
- **オプションの自動化** – Orbekにクエストを自動で、複数同時に実行させられます。初期設定はオフ – Discordが禁止しているため自己責任で。
- **自動でアップデート** – 新しいバージョンはGitHubのリリースから取得し、SHA-256で確認します。12言語対応。

## チュートリアル

1. **Orbekをダウンロードして起動** – プロジェクトページからOrbek.exeをダウンロードし、専用のフォルダーに入れて起動します。時計の横にアイコンが表示されます。
2. **「すべてインストール」をクリック** – セットアップタブでOrbekがNode.jsとVencordをダウンロードし、プラグインを入れてビルドし、Discordに組み込みます。数分かかります。
3. **Discordが自動で再起動** – セットアップ後、DiscordがOrbekプラグイン付きで再起動します。ウィンドウ下部の「Discord接続中」が緑になります。
4. **クエストを見る** – ゲーム・動画・Orbsタブ、並べ替え、コスメのフィルター。各クエストに報酬、進行状況、残り時間が表示されます。
5. **受注して受け取る** – 「クエストを受ける」でクエストを受注します。完了したら「Discordで順番に受け取る」をクリック – Discordが報酬を順番に表示し、CAPTCHAが出たときだけ解きます。
6. **自動化 – 自己責任で** – 設定でOrbekにクエストを自動で、複数同時に実行させられます。Discordはこれを禁止しており、報酬の取り消しやアカウント停止の可能性があります。
7. **ミニ表示** – 表示を「ミニ」に切り替えるか「小さいウィンドウ」を開くと、報酬と進行リングだけが見られます。
8. **アップデート** – OrbekはGitHubから自動で更新されます。新しいプラグインが出ると「プラグインを更新」のバーが表示されます。

## よくある質問

**使っても大丈夫？**  
クエストの閲覧や受注はDiscord自身がしていることと同じです。自動で実行するのはDiscordのルール違反で、報酬の取り消しやアカウント停止の可能性があります。

**OrbekはDiscordのパスワードやトークンを見ますか？**  
いいえ。すべてあなたのDiscordアプリ内のプラグインを通ります。Orbekが受け取るのはクエスト一覧だけで、トークンはDiscordの外に出ません。

**Vencordとは？**  
PC版Discordアプリ向けの人気のMODです。Orbekのプラグインはその中で動き、セットアップが代わりにインストールします。

**Windowsが不明な発行元と警告します。**  
ファイルにはコード署名がありません。ソースは公開されており、各リリースはGitHub Actionsでビルドされます。

## ソースからビルド

Go 1.24以降：

```
go build -trimpath -ldflags "-H=windowsgui -s -w" -o Orbek.exe .
```

## 免責事項

Discordのクエストを自動で実行することはDiscordのルールに反します。OrbekはDiscordとは関係ありません。自己責任でご利用ください。
